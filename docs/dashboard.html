    How a change ships

    1. Developer opens a pull request
    2. Tests, Gitleaks and CodeQL run in parallel
    3. Image is built and scanned by Trivy
    4. Merge is allowed only if all checks pass
    5. Image is pushed, deployed to staging, then production after approval
