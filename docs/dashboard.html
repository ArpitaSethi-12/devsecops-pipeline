DevSecOps pipeline for a Node.js API

The plan: every push will go through automated tests and four security checks before it can be merged or deployed. If any check fails, the code will be blocked.

      How a change will ship

      1. Developer opens a pull request
      2. CI runs tests, secret scan and code scan
      3. Image is built and scanned by Trivy
      4. Merge is allowed only if all checks pass
      5. Clean image is pushed and deployed
